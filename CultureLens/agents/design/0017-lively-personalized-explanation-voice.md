# 0017 — 更有个性的个性化 AI 讲解

- 状态：已实现（2026-08-06）

## 背景

现有讲解已经会根据用户知识状态跳过已知内容、补齐缺口，但系统提示词强调约束与段落结构，实际语气容易变成平直的说明书。用户希望它更活泼，并能感到讲解是从自己已走过的文化路径继续展开。

## 决策

1. 在 `explain.txt` 中把助手定位为“熟悉现场、乐于分享的文化同伴”：从已给资料中真实存在的线索、反差或观看角度切入，用自然的第二人称引导和有节奏的短段落组织内容。
2. 个性化从两个已有输入同时体现：优先衔接相关的 `user_knowledge_states`，并以 `preference_profile` 选择补充角度。两者只影响切入和叙述重点，不暴露“画像”或系统推断过程，也不揣测用户身份、情绪或未提供的偏好。
3. 保留原有事实边界：所有实质内容仍只能来自本地知识片段、图谱邻居和关联维度；比喻只能帮助理解已知内容，不能引入新年代、人物、轶事或关系。避免空泛赞美、卖萌和高密度感叹号。
4. 讲解的语义已变化，`CultureExplanationCache` 的 schema/key 与落盘文件从 v1 升至 v2，使旧缓存不会继续返回冷淡的旧文案。缓存容量、清理入口和失败回退行为不变。

## 验证

- 讲解缓存键测试断言 v2 前缀，并保留用户知识状态和语言差异的回归覆盖。
- 执行 CultureLens 的 `build-for-testing`，确认 prompt 资源、缓存服务和测试 target 一起编译。
- 待真机验证：使用不同知识图谱状态扫描同一对象，确认开篇、衔接角度和语气均有区别，且刷新讲解会得到新版本结果。
