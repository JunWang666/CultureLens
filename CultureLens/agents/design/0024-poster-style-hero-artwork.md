# 0024 — 无照片对象的海报感示意图

## 背景

杂志化视觉语言（见 `PROJECT.md`）以细线分栏、留白与宋体标题为主，克制、可读，但作为「示意图」出现的 `ObjectArtwork`（对象/景点无实拍照片时的占位图，用于列表卡、分享卡）此前是柔和渐变 + 描边同心圆 + 半透明 hierarchical 图标，视觉冲击力偏弱，尤其在分享到社交渠道时不够抓人。

## 决策

1. **`ObjectArtwork` 改为扁平撞色对角构图**：主色块（朱砂或墨色，二选一）铺满画面，另一色以对角三角形压角，接缝处叠一条细金线（呼应既有 hairline 语汇，但放大到海报尺度）。
2. **示意 SF Symbol 放大加粗**，实色宣纸白填充、加投影，取代原来的半透明 hierarchical 描边风格，强化剪影感。
3. **主色块按对象 `id` 确定性交替**（朱砂主 / 墨色主），让同一列表里的多张卡片有节奏感，而非重复同一张底图；同一对象每次渲染结果不变。
4. 此高对比处理**仅用于这一个「示意图」槽位**（列表卡缩略图、分享卡导出图），不扩散到详情页正文、知识卡片等阅读场景——延续「首页/封面可以强烈，正文必须安静」的原则。

## 非目标

- 不引入新的品牌色或新组件；仍完全复用 `CultureTheme`（`cinnabar` / `inkPrimary` / `antiqueGold` / `canvas`）。
- 不改变 `ObjectArtwork` 的调用签名（`object` / `height`），`CultureObjectCard`、分享卡渲染路径无需改动。
- 不处理有实拍照片的场景（`magazinePhoto()` 暖调统一处理路径不变）。
