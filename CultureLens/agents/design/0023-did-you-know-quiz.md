# 0023 探索首页「你知道吗？」文化问答

- 状态：已实现（2026-08-07）

## 背景

探索首页已经展示附近看点、点亮图鉴、收集、封面故事与下一看点，但用户遇到过的知识节点只以进度和图谱形式回看，缺少轻量、可即时互动的记忆反馈。

## 产品语义

- 新增「你知道吗？」板块，从 `KnowledgeProgressStore` 中能够解析到当前知识包的已接触节点出题；没有已接触节点时显示引导文案，不向网络请求。
- 每题固定三个选项且仅一个正确答案。用户选择后立即显示正误与简短解释，不修改节点的接触 / 理解 / 掌握等级，避免一次选择直接冒充真实掌握。
- 支持「换一题」：按稳定排序轮换到下一个已接触节点。重新进入页面默认以“日期 + 已接触节点集合”确定当天起始节点，让内容有每日变化但不会因视图重建不断跳动。
- 题目严格根据传入的本地知识正文生成；模型不得补充正文没有的事实。板块标明题目对应的知识节点，并可进入该节点详情复习。

## LLM 契约

- 复用 `LLMGatewayClient.completeText`，因此请求固定走 `LLMGatewayConfig.chat`（`dynamic/chat`），并关闭 thinking。
- 输入只包含节点 UUID、名称和知识包正文，所有字段均声明为不可执行的数据。
- 输出为单个 JSON 对象：`question`、`options`、`correct_index`、`explanation`。客户端要求：
  - `question` / `explanation` 去空白后非空；
  - `options` 恰好三项、去空白后非空且互不重复；
  - `correct_index` 在 `0...2`；
  - 输出语言跟随 `AppLanguage`。
- JSON 不符合约束时视为生成失败，不展示未经校验的自由文本。

## 缓存与数据流

- `DidYouKnowQuizService` 为 actor，负责缓存读取、请求合并、生成、校验和原子写入。
- 缓存位于 `Library/Caches/CultureLens/DidYouKnow/`，每题一个 JSON 文件；缓存键为 `schemaVersion + language + element UUID + 知识正文摘要`。相同节点、语言、正文和契约版本优先命中缓存，不重复调用 LLM；知识包正文更新后自动生成新题。
- 缓存是可再生网络产物，纳入 `AppCacheManager.clearAll()` 和 `usageBytes()`；清理后需要时重新生成。
- UI 用 `.task(id:)` 跟随“目标节点 + 语言”加载；取消页面或切题时，旧任务正常取消，不能覆盖新题状态。

## 页面布局与状态

- iPad / 横屏双栏：固定放在左栏「附近看点」下方；原先附近为空时移到左栏的「封面故事」继续排在它后面。
- iPhone / 单栏：放在「附近看点」后、点亮图鉴前。
- 状态包含：无已接触节点、加载中、已加载未作答、已作答、失败。失败态提供重试，不影响首页其他内容。
- 视觉沿用杂志排版：栏目头、细分隔线、大标题与朱砂强调；不用新增与全局视觉语言冲突的游戏卡片体系。
- 选项提供至少 44pt 点击高度、明确的 VoiceOver 标签；正误反馈不仅依赖颜色。

## 验证

- 单测覆盖 JSON 提取与校验、缓存键的语言隔离、同一节点缓存命中不重复生成，以及错误选项数量 / 越界答案拒绝。
- 编译验证覆盖 App 与 unit-test target；手工验证双栏位置、单栏顺序、切题取消、无网缓存命中和语言切换。
