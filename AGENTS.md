# CultureLens

SwiftUI iOS app for on-device culture recognition and exploration (`CultureLens/`).

## Cursor Cloud specific instructions

The iOS app requires macOS + Xcode and cannot be built or run on the Linux cloud VM. Prefer working on this repo from a Mac with Xcode.

Project orientation and design notes live under `CultureLens/agents/` (see `PROJECT.md`). Standard run instructions are in `README.md`.
